Computer Engineering student at **Baku Engineering University**, specializing in **Data Science** and **AI Engineering**. I work through the full analysis loop: inspect the data, clean it, explore it, train a model, and evaluate whether the result is actually useful.

On GitHub that looks like Jupyter notebooks in Python — pandas, NumPy, Matplotlib, Seaborn, and scikit-learn — plus C# coursework from the engineering programme. I am building toward shipping ML systems, not only running cells in a notebook.

- **Regression EDA:** King County house sales (`kc_house_data`)
- **Software foundation:** C# labs and small apps alongside the DS track

Open to internships and collaboration in data science, machine learning, and AI engineering.
